## 🧪 Problem-solving template

For every problem:

1. Understand the input/output.
2. Identify the pattern.
3. Start with a brute-force idea.
4. Find the bottleneck.
5. Optimise using the right data structure or algorithm.
6. Analyse time and space complexity.
7. Test edge cases.

## 💼 Interview patterns

**Must-master:** Two Sum, Prefix Sum, Two Pointers, Sliding Window, Binary Search, Fast & Slow Pointers, Monotonic Stack, BFS, DFS, Topological Sort, Dijkstra, Union-Find, Greedy, 1D DP, 2D DP, Knapsack, Backtracking.

## 🎯 Goal

Build the ability to recognise algorithmic patterns instead of memorising isolated solutions.

> **Think → Pattern → Optimise → Code → Test → Explain**
